## dashboard-design-v8 翻转动画黑屏 Bug 分析

**问题现象**: 点击 BotCard 的 View 按钮后，卡片翻转完成变成全黑。

**根因定位** (assets/index-B0e2ws0M.js 源码分析):
- `AnimatePresence mode="wait"` 导致正反面动画顺序执行
- 正面退出动画 rotateY:0→-180 耗时 0.5s，且 `backfaceVisibility: hidden`
- 正面旋转超过90°后消失，背面因 `mode="wait"` 需等正面完全退出才进入
- 结果：中间约0.5秒空档期，两个卡片都不可见 → 全黑

**修复方案**:
1. 将 `mode="wait"` 改为 `mode="popLayout"` 或默认 `"sync"`，让正反面同步翻转
2. 或将动画时长从 0.5s 缩短到 0.2s，减少空档期

**文件位置**: `/home/cheche/dashboard-design-v8/assets/index-B0e2ws0M.js`
**CSS位置**: `/home/cheche/dashboard-design-v8/assets/index-DqrkwGhM.css`
**备份版本**: `/home/cheche/dashboard-design-v8-backup-202605121736/`

start_pos = content.find('yc=[')
bracket_count = 0
for i in range(start_pos, len(content)):
    if content[i] == '[': bracket_count += 1
    elif content[i] == ']': 
        bracket_count -= 1
        if bracket_count == 0: 
            end_pos = i + 1
            break
new_content = content[:start_pos] + new_yc + content[end_pos:]
