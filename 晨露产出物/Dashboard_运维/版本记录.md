## 产出物去重逻辑说明（2026-05-08 更新）

Dashboard 背面显示产出物时，需要**去重 + 保留最新版本**。

### 规则

1. **同一主题只出现一次**
   - 功能词后缀视为同一主题：`方案`/`计划`/`规划`/`清单`/`记录` 等
   - 例：`通晓平台宣传方案_V1.0` + `通晓平台宣传计划_V2.1` → 只保留一个

2. **保留版本号最新的**
   - 提取 `_v1.0` / `V2.1` / `_01` 等版本号
   - 按数字比较：`V2.1 > V1.0`，保留 V2.1

3. **slide 系列统一**
   - `slide07_169.png` / `slide_01.png` / `slide1.png` → 都视为 `slide`
   - 同一系列只保留最新一张

4. **正面数量 vs 背面列表**
   - 正面：显示过滤后**不重复的文件总数**
   - 背面：显示**3个最新产出物**（按时间排序）

### 处理顺序

```
文件名 → 去除版本号 → 去除功能词 → 得到主题名
主题名相同 → 比较版本号 → 保留版本号大的
```

| 宣传计划_V2.1.md | 宣传 | [2,1] | ✅ 保留 |
| slide07_169.png | slide | [] | ✅ 保留（最新slide） |
| slide01_169.png | slide | [] | ❌ 被覆盖 |
