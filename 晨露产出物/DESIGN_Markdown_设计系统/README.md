## 🚀 使用方法

### 1. 选择设计风格
根据项目类型选择合适的 DESIGN.md：
- 做后台/工具 → 选 **Linear** 或 **Vercel**
- 做内容/笔记 → 选 **Notion**
- 做展示/品牌 → 选 **Apple** 或 **Figma**
- 做娱乐/社交 → 选 **Spotify**

### 2. 复制到项目
```bash
cp "Linear_DESIGN.md" ~/你的项目/DESIGN.md
```

### 3. 告诉 AI 使用
> "参考 DESIGN.md 的设计风格，帮我做一个登录页面"

AI 会自动读取其中的：
- 🎨 色彩系统（背景/文字/强调色）
- 🔤 字体规范（字体、字号、字重）
- 📦 组件样式（按钮、卡片、输入框）
- 📐 间距和布局规则
