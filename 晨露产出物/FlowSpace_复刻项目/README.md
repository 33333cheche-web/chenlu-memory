## 🎯 核心功能

- 🌧️ **动态背景** - 雨天/下雪/星空 Shader 效果
- 🎵 **白噪音** - 氛围音效配合场景
- ✍️ **沉浸编辑器** - 毛玻璃无边框输入框
- ⏱️ **心流计时器** - 番茄钟 + 休息提醒
- 💾 **自动保存** - LocalStorage 实时存储
