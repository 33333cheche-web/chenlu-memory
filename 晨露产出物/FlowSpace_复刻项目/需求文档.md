# FlowSpace 产品复刻 - 需求文档

**项目**: FlowSpace 沉浸式写作工具复刻  
**来源**: 小红书博主 Mao 的产品分享视频  
**风格**: 赛博禅意 (Cyber Zen) / 极简主义  
**创建时间**: 2026-04-08  
**状态**: 需求分析完成，待开发

---

## 📋 产品概述

一个沉浸式的写作/思考工具，通过动态自然背景（雨、雪、星空）配合白噪音，帮助用户进入心流状态。

**核心体验**: 打开页面 → 选择氛围 → 开始写作 → 自动保存 → 随时回顾

---

## 🎯 功能模块

### 一、视觉底座 (The Canvas)
**WebGL/Shader 全屏动态背景**

| 模式 | 视觉效果 | 白噪音 |
|------|---------|--------|
| **雨天 (Rain)** | 玻璃质感雨滴、窗外雨景 | 雨声 |
| **下雪 (Snow)** | 飘落雪花、雪景背景 | 风声+雪声 |
| **星空 (Star)** | 夜晚星空、山景轮廓 | 夜晚虫鸣 |

**技术要求**:
- WebGL Shader 实现粒子效果
- 响应式，适配不同屏幕尺寸
- GPU 优化，保持 60fps

---

### 二、沉浸编辑器 (The Deck)
**无边框毛玻璃输入框**

**功能**:
- 全屏无边框文本输入区域
- 毛玻璃效果 (backdrop-filter: blur)
- 三种内置字体切换
  - 无衬线 (Inter / SF Pro)
  - 衬线 (Georgia / 思源宋体)
  - 手写体 (等Future实现)

**交互**:
- 点击即输入
- 自动保存到 LocalStorage
- 支持 Markdown 基础语法

---

### 三、氛围控制台 (Vibe Mixer)
**隐藏式浮窗，鼠标移入显示**

**控制项**:
| 滑杆 | 范围 | 默认值 |
|------|------|--------|
| 雨量/雪量 | 0-100% | 50% |
| 模糊度 | 0-100% | 30% |
| 白噪音音量 | 0-100% | 40% |
| 音乐融合度 | 0-100% | 20% |

**UI 样式**:
- 底部居中悬浮
- 毛玻璃卡片
- 滑杆采用品牌色（赛博紫/青色）

---

### 四、心流计时器 (Zen Timer)
**极简倒计时**

**模式**:
- **专注模式**: 25分钟倒计时（番茄钟）
- **休息提醒**: 5分钟休息倒计时
- **自由模式**: 正计时

**UI**:
- 线性进度条或环形消融效果
- 极简数字显示
- 完成时柔和提示（不打扰）

---

### 五、数据管理 (Privacy)
**纯前端存储**

**功能**:
- LocalStorage 实时暂存
- 支持导出 .txt 文件
- 历史记录列表
- 单条删除/清空

**隐私**:
- 不上传任何数据到服务器
- 用户完全掌控自己的内容

---

## 🎨 视觉规范

### 色彩系统
| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#0a0a0f` | 接近纯黑 |
| 毛玻璃背景 | `rgba(255,255,255,0.05)` | 半透明 |
| 主文字 | `#f7f8f8` | 柔和白 |
| 次要文字 | `#8a8f98` | 灰色 |
| 品牌强调 | `#5e6ad2` | 赛博紫 |
| 交互高亮 | `#7170ff` | 亮紫 |

### 字体规范
- **主字体**: Inter / SF Pro Display
- **字重**: 400 (正文), 510 (强调), 590 (标题)
- **行高**: 1.6 (舒适阅读)

### 交互规范
- **非活跃状态**: UI 透明度 0% (完全隐藏)
- **鼠标移入**: 优雅淡入 (300ms ease-out)
- **触发区域**: 屏幕边缘 50px

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 Canvas / WebGL | 动态背景渲染 |
| Three.js (可选) | 3D 星空效果 |
| CSS backdrop-filter | 毛玻璃效果 |
| Web Audio API | 白噪音生成/控制 |
| LocalStorage API | 本地数据存储 |
| FileSaver.js | 导出 txt 文件 |
