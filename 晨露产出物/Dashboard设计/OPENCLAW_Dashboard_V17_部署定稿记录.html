技术方案详情

1. 静态文件服务

# 使用 Python 内置 HTTP 服务器（生产环境建议用 Nginx） python3 -m http.server 8080 --bind 0.0.0.0 # 后台运行（nohup 或 systemd） nohup python3 -m http.server 8080 --bind 0.0.0.0 > /dev/null 2>&1 &

2. Cloudflare Tunnel 配置

# 启动隧道（已配置为服务） cloudflared tunnel run 6804dec3-c3fb-4bd8-b216-493cfcd2d3bb # 隧道配置指向 localhost:8080 # 公网域名: dashboard.cheche-dashboard.site

3. 缓存清理策略（无 Cloudflare 仪表盘权限）

核心原则: 重命名文件 + Query Params 强制刷新
# 1. 重命名被缓存的文件 mv avatar-mumu.jpg avatar-mumu-v2.jpg # 2. 更新所有引用 sed -i 's/avatar-mumu\.jpg/avatar-mumu-v2.jpg/g' assets/index-*.js # 3. 添加版本号强制浏览器刷新 # index.html 中: <script src="assets/index-CvyKvTWc.js?v=7">script>

4. 修改 Minified JS 的安全方法

警告: 绝对不能用正则全局替换（如 re.sub(r'yc=\[.*\]', ...)），会导致匹配范围过大、截断文件！
# 正确方法：精确字符定位 + 手动括号计数 start_pos = content.find('yc=[') bracket_count = 0 for i in range(start_pos, len(content)): if content[i] == '[': bracket_count += 1 elif content[i] == ']': bracket_count -= 1 if bracket_count == 0: end_pos = i + 1 break new_content = content[:start_pos] + new_yc + content[end_pos:]

关键经验教训

修改 minified JS 绝对不能用正则全局替换
正则 re.sub(r'yc=\[.*\]', ...) 会匹配到最远匹配的 ]，导致截断整个 JS bundle。 必须使用精确字符定位 + 手动括号计数。
产出物映射前必须查看实际工作区
不能假设目录结构（如 Charles ≠ 晨露早报）。必须先 find/ls 各 Bot workspace 确认真实产出物，再进行映射。
Cloudflare CDN 缓存处理
无仪表盘权限时，重命名文件是最可靠的缓存清除方法。配合 ?v=N query params 强制浏览器刷新。
每次修改前必须备份
cp index.js index.js.bak.safe — 出问题可以秒级回滚，避免服务长时间不可用。
