📱 iPhone 14 Pro - 适配后效果

🛠️ 具体修改内容

📐

布局优化：双列 → 单列

手机屏幕宽度有限，6个Bot卡片从双列布局改为单列纵向排列，避免信息拥挤，每个卡片都有足够的展示空间。

/* 移动端单列布局 */ @media (max-width: 640px) { .bot-grid { grid-template-columns: 1fr; gap: 12px; } }
👆

触摸优化：增大点击区域

将Bot卡片改为横向布局，头像增大到48px，整个卡片可点击，符合 iOS 人机界面指南的 44px 最小点击区域要求。

/* 触摸反馈 */ .bot-card { min-height: 44px; } .bot-card:active { transform: scale(0.98); opacity: 0.9; }
📱

Event Stream 重新设计

时间轴从横向改为纵向卡片式布局，每个事件独立成卡片，显示Bot名称、时间、完整描述，信息层次更清晰。

/* 移动端Event Stream */ .event-item { padding: 12px 0; border-bottom: 1px solid rgba(255,255,255,0.05); } .event-bot { font-size: 12px; color: #e94584; }
🔤

字体大小优化

增大基础字体到16px（防止iOS自动缩放），调整标题、正文、辅助文字的层级关系，确保小屏幕可读性。

/* 防止iOS缩放 */ @media (max-width: 640px) { body { font-size: 16px; } .section-title { font-size: 11px; } .bot-name { font-size: 14px; } }
