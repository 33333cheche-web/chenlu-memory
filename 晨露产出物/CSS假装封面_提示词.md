# CSS 假装项目封面 - 提示词

把这个提示词发给 AI（ChatGPT / Claude / Kimi），让它帮你生成用 CSS 画的假项目封面：

---

## 提示词正文

请为我的网页作品集生成 4 个项目封面，**不要引用任何外部图片**（不用图床、不用 placeholder），完全用 CSS 绘制假的界面效果图。

### 项目列表：
1. **云笔记应用** — 画一个手机界面 mockup，有屏幕、状态栏、笔记内容行、标签
2. **电商后台系统** — 画一个 Dashboard 界面，有侧边栏导航、头部标题、数据图表区域
3. **健康追踪小程序** — 画一个健康数据卡片，有圆形进度条、统计数字、心率图标
4. **企业品牌设计** — 画一个 Logo 展示效果，有圆形背景、字母 Logo、品牌名称

### 技术要求：
- 纯 HTML + CSS，不依赖任何图片资源
- 使用 div 嵌套 + CSS 渐变/阴影/圆角/伪元素来模拟真实界面
- 每个封面尺寸约 280px × 200px
- 配色风格统一：主色 #1a1a2e（深蓝黑），强调色 #c45c3e（砖红），背景 #f5f5f7
- 添加适当的阴影和圆角让 mockup 有立体感
- 悬停时有微妙的放大或阴影变化效果

### 输出格式：
直接输出完整的 CSS 代码块（包含 .project-visual-1 / .project-visual-2 / .project-visual-3 / .project-visual-4 四个类），以及对应的 HTML 结构，我直接复制粘贴就能用。


## 效果原理

**为什么用 CSS 画假界面比图片更好：**

1. **零依赖** — 不需要图床、不担心图片加载失败
2. **零流量** — 不消耗任何网络请求
3. **矢量清晰** — 任何分辨率都清晰，不会模糊
4. **可交互** — 可以添加 hover 动画、过渡效果
5. **体积小** — 几行 CSS 比一张 JPG 小得多
6. **可编辑** — 随时改颜色、改布局、改内容

**核心技巧：**
- 用 `box-shadow` 创建立体感（手机厚度、卡片悬浮）
- 用 `linear-gradient` 做图表、进度条、背景
- 用 `::before` / `::after` 伪元素做装饰符号
- 用多个嵌套 `div` 拼出复杂结构（侧边栏 + 主内容区）
- 用 `border-radius` 做圆形进度、圆角卡片、手机轮廓

```
请为我的作品集生成 4 个 CSS 绘制的项目封面 mockup，要求：

1. 云笔记：画一个 iPhone 样式手机，屏幕内显示 5 行笔记文字（用灰色横线模拟），底部有一个红色标签"笔记"

请输出完整的 HTML + CSS 代码，我可以直接复制使用。
```
