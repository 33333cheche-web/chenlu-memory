# Frontend Design Skills 安装前后提示词对比

## 安装前 — 普通提示词

> "帮我做一个个人作品集网页，展示几个项目，好看一点。"

**输出结果：** 灰色导航栏、蓝色方块按钮、无边框卡片、Arial字体、无动效——典型的"能用但丑"网页。

---

## 安装后 — 同样意思，截然不同的输出

> "帮我做一个个人作品集 landing page。参考 Apple 官网的设计语言：大量留白、精致的排版层次、圆角卡片、细腻的 hover 动效（cubic-bezier缓动）、渐变文字标题。使用 CSS Variables 管理设计令牌。"

**输出结果：** 设计系统完备、视觉层次清晰、动效丝滑、字体排印考究——产品级设计质量。

---

## 核心差异一句话

**同样的需求，不同的表达能力。**

| 维度 | 安装前 | 安装后 |
|------|--------|--------|
| **设计系统** | 颜色/间距随意写死 | CSS Variables + Design Tokens |
| **视觉层次** | 平铺直叙 | 大小对比、留白节奏、渐变层次 |
| **响应式** | 基本不考虑 | clamp() + Grid + 媒体查询 |
| **动效交互** | 无或生硬 | cubic-bezier 缓动、hover 微交互 |
| **字体排印** | Arial/默认字体 | 系统字体栈、精细化字距行高 |
| **代码质量** | 随意堆砌 | 语义化、模块化、可维护 |
| **风格还原** | 通用模板 | 精准还原 Apple/Linear 等设计语言 |

---

## 使用建议

把这段提示词放在对比 HTML 的顶部或做成卡片插入页面中，让观众一眼明白：**不是提示词变了，是 AI 的设计能力变了。**
