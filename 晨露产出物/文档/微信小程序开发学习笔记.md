## 📱 小程序架构

### 文件结构
```
project/
├── app.js              # 小程序逻辑
├── app.json            # 全局配置
├── app.wxss            # 全局样式
├── pages/
│   ├── index/          # 首页
│   │   ├── index.js    # 页面逻辑
│   │   ├── index.json  # 页面配置
│   │   ├── index.wxml  # 页面结构
│   │   └── index.wxss  # 页面样式
│   └── ...
├── components/         # 自定义组件
├── utils/              # 工具函数
└── images/             # 图片资源
```

### 核心技术栈
| 技术 | 说明 | 对应 Web |
|-----|------|---------|
| **WXML** | 页面结构 | HTML |
| **WXSS** | 页面样式 | CSS |
| **JavaScript** | 页面逻辑 | JS |
| **JSON** | 配置文件 | - |

## 💡 关键概念

### 1. 数据绑定
```xml
<!-- WXML -->
<view>{{message}}</view>
<button bindtap="changeMessage">点击</button>
```

```javascript
// JS
Page({
  data: {
    message: 'Hello World'
  },
  changeMessage() {
    this.setData({
      message: 'Hello Mini Program'
    })
  }
})
```

### 2. 条件渲染
```xml
<view wx:if="{{isNoteMode}}">笔记模式</view>
<view wx:else>任务模式</view>
```

### 3. 列表渲染
```xml
<view wx:for="{{taskList}}" wx:key="id">
  <checkbox checked="{{item.completed}}"/>
  <text>{{item.content}}</text>
</view>
```

### 4. 本地存储
```javascript
// 存储数据
wx.setStorageSync('notes', notesArray);

// 读取数据
const notes = wx.getStorageSync('notes') || [];
```

## 🔐 最佳实践（来自官方）

1. **追求零异常** - 保证程序高鲁棒性
2. **使用 HTTPS** - 更安全，防篡改
3. **按需引入 WXSS** - 减少包体积
4. **兼容基础库版本** - 注意 API 兼容性
5. **用户授权** - 合理请求权限

| 页面 | 功能 |
|-----|------|
| **首页** | 快速输入、分类展示、最近编辑 |

### 数据结构
```javascript
// 笔记/任务项
{
  id: 'uuid',
  type: 'note' | 'task',     // 类型：笔记或任务
  content: '内容',
  category: '工作/生活/随笔',
  completed: false,           // 任务完成状态
  createTime: timestamp,
  updateTime: timestamp
}

// 分类
{
  id: 'work',
  name: '工作',
  icon: '💼',
```
