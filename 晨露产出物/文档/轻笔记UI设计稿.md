# 轻笔记小程序 UI 设计稿

## 🎨 整体风格
- **主色调**：柔和蓝色系 `#5B9BD5`
- **背景色**：浅灰蓝 `#F0F4F8`
- **辅助色**：淡蓝 `#B8D4E8`
- **文字主色**：深灰蓝 `#4A5568`
- **圆角**：统一使用 16-24rpx 圆角，柔和友好

## 📝 笔记模式 vs ☑️ 任务模式

### 笔记模式输入区
```
┌─────────────────────────────┐
│  ┌───────────────────────┐  │
│  │ 今天想写点什么...      │  │
│  │                       │  │
│  │ 这里可以写长文本，      │  │
│  │ 支持多行输入...        │  │
│  │                       │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

### 任务模式输入区
```
┌─────────────────────────────┐
│  ┌───────────────────────┐  │
│  │ ☐ 完成产品需求文档     │  │
│  │ ☑ 回复客户邮件        │  │  ← 已完成带勾选
│  │ ☐ 准备周会材料         │  │
│  │ + 添加新任务           │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

## 🎨 配色方案

| 用途 | 颜色值 | 预览 |

| 卡片背景 | `#FFFFFF` | ████ 纯白 |
| 次要背景 | `#F8FAFC` | ████ 极浅灰 |
| 边框色 | `#E2E8F0` | ████ 浅灰 |
| 文字主色 | `#4A5568` | ████ 深灰蓝 |
| 文字次要 | `#718096` | ████ 中灰 |
| 文字浅色 | `#A0AEC0` | ████ 浅灰 |
