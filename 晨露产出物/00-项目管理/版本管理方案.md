# OpenClaw 项目版本管理方案

## 现状问题

当前项目存在版本管理痛点：
- 配置文件修改后可能无法回退（如 Baby 的 mem0 误删）
- 产出物版本命名不统一（`v1定稿`、`v2修改`、`最终版`混用）
- 无版本历史追溯，排查问题困难
- Dashboard 多次迭代但无版本记录

---

## 推荐方案：三层版本管理

### 第一层：代码/配置版本控制（Git）

**范围**：
- 所有 `.openclaw.json` 配置文件
- Dashboard HTML/Python 源码
- 各 Bot 的核心配置文件

**规范**：
```bash
# 初始化（已有 GitHub 备份基础上扩展）
cd /home/cheche/.openclaw/workspace-chenlu
git init  # 如果还没初始化
git remote add origin https://github.com/33333cheche-web/chenlu-memory.git

# 提交规范
# feat: 新功能（如新增 Bot 配置）
# fix: 修复（如修复 Baby 启动失败）
# refactor: 重构（如清理 mem0 残留）
# docs: 文档（如更新运维手册）
# style: 样式（如 Dashboard 风格调整）
```

**必须纳入 Git 的文件**：
```
workspace-*/
  ├── .openclaw/openclaw.json      ← 核心配置
  ├── openclaw-dashboard.py        ← Dashboard 源码
  ├── dashboard-*.html             ← Dashboard 模板
  ├── memory/
  │   ├── active-tasks.md          ← 任务状态
  │   └── learnings.md             ← 经验教训
  └── 晨露产出物/
      ├── 版本记录.md              ← 产出物版本日志
      └── 各项目文件夹/
```

### 第二层：产出物语义化版本（Semantic Versioning）

**命名规范**：
```
项目名_类型_v主版本.次版本.修订号_状态_日期.扩展名

示例：
轻笔记_小程序_v1.0.0_定稿_20260328.zip    ← 正式发布版
轻笔记_小程序_v1.1.0_修改_20260402.zip    ← 功能迭代
轻笔记_小程序_v1.0.1_修复_20260405.zip    ← Bug修复
Dashboard_v5.0.0_定稿_20260508.html        ← 大版本
Dashboard_v5.1.0_修改_20260511.html        ← 小迭代
```

**版本号规则**（遵循 SemVer）：
| 版本变化 | 说明 | 示例 |
|---------|------|------|
| **主版本+1** | 重大重构/不兼容变更 | v5 → v6（暗黑风格全面改版） |
| **次版本+1** | 功能新增/较大调整 | v5.0 → v5.1（新增密码验证） |
| **修订号+1** | Bug修复/微调 | v5.0.0 → v5.0.1（修复按钮对齐） |

**状态标记**：
- `初稿` - 第一版草稿
- `修改` - 根据反馈调整中
- `定稿` - 已确认的最终版本
- `归档` - 历史版本，不再使用

### 第三层：配置文件快照备份

**自动化脚本**（建议添加到 crontab）：
```bash
#!/bin/bash
# /home/cheche/scripts/config-snapshot.sh
# 每天 23:00 自动备份所有 Bot 配置

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/home/cheche/config-backups/$DATE"
mkdir -p "$BACKUP_DIR"

for bot in main baby bot2 rainbow mumu melody; do
  if [ "$bot" = "bot2" ]; then
    cp "/home/cheche/.openclaw-bot2/openclaw.json" "$BACKUP_DIR/openclaw-${bot}.json"
  elif [ "$bot" = "main" ]; then
    cp "/home/cheche/.openclaw-main/.openclaw/openclaw.json" "$BACKUP_DIR/openclaw-${bot}.json"
  else
    cp "/home/cheche/.openclaw-$bot/.openclaw/openclaw.json" "$BACKUP_DIR/openclaw-${bot}.json"
  fi
done

cp "/home/cheche/openclaw-dashboard.py" "$BACKUP_DIR/"
cp "/home/cheche/dashboard-v5.html" "$BACKUP_DIR/"

# 保留最近 30 天
find /home/cheche/config-backups -maxdepth 1 -type d -mtime +30 -exec rm -rf {} \;

echo "[$DATE] Config snapshot saved to $BACKUP_DIR"
```

**手动备份触发时机**：
- 修改配置前（必须！）
- 升级插件后
- 重大调整前

**备份命名**：
```
config-backups/
  ├── 20260511_121135/          ← 自动备份
  │   ├── openclaw-main.json
  │   ├── openclaw-baby.json
  │   └── ...
  ├── 20260511_161800_pre-mem0-cleanup/  ← 手动备份（加描述）
  └── ...
```
