## 二、文件上传 / 下载

### 方法一：SCP 命令行（推荐）

**上传文件到服务器**（本地 → 服务器）：
```bash
# 上传单个文件
scp 本地文件路径 root@47.107.183.171:/opt/nike-dam-backend/static/

# 上传整个文件夹
scp -r 本地文件夹路径 root@47.107.183.171:/opt/nike-dam-backend/
```

**从服务器下载文件**（服务器 → 本地）：
```bash
# 下载单个文件
scp root@47.107.183.171:/opt/nike-dam-backend/static/index.html ./

# 下载整个文件夹
scp -r root@47.107.183.171:/opt/nike-dam-backend ./备份文件夹/
```

### 方法二：SFTP 交互式（适合批量操作）

```bash
sftp root@47.107.183.171
# 输入密码: nike@2026

# 常用命令：
put 本地文件 服务器路径      # 上传
get 服务器文件 本地路径      # 下载
ls                           # 查看服务器当前目录
lls                          # 查看本地当前目录
cd 服务器目录                # 切换服务器目录
lcd 本地目录                 # 切换本地目录
exit                         # 退出
```

### 方法三：VS Code + Remote-SSH 插件（推荐图形化操作）

1. VS Code 安装 `Remote - SSH` 插件
2. 按 `Cmd+Shift+P`（Mac）或 `Ctrl+Shift+P`（Windows），输入 `Remote-SSH: Connect to Host...`
3. 输入：`ssh root@47.107.183.171`
4. 输入密码：`nike@2026`
5. 连接成功后，左侧文件树直接显示服务器文件，像操作本地文件一样拖拽/编辑

## 三、常用服务器操作命令

### 查看项目文件
```bash
ssh root@47.107.183.171

# 进入项目目录
cd /opt/nike-dam-backend

# 查看文件列表
ls -la

# 查看前端文件
ls -la static/
```

### 编辑文件（命令行）
```bash
# 用 nano 编辑（简单）
nano /opt/nike-dam-backend/static/index.html

# 用 vim 编辑（功能多）
vim /opt/nike-dam-backend/static/index.html

# 退出 vim：先按 Esc，然后输入 :wq 回车保存退出
```

### 重启后端服务
```bash
# 杀死现有进程
pkill -f uvicorn

# 重新启动（后台运行）
cd /opt/nike-dam-backend
nohup venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000 > /dev/null 2>&1 &

# 验证服务是否启动
curl http://localhost:8000
```

### 查看服务日志
```bash
# 查看实时日志（如果有日志文件）
tail -f /opt/nike-dam-backend/nohup.out

# 查看最近100行日志
tail -n 100 /opt/nike-dam-backend/nohup.out
```

### 查看数据库
```bash
# 进入 SQLite 数据库
sqlite3 /opt/nike-dam-backend/nike_dam.db

# 查看所有用户
sqlite3 /opt/nike-dam-backend/nike_dam.db "SELECT id, username, role FROM users;"

# 查看所有图片
sqlite3 /opt/nike-dam-backend/nike_dam.db "SELECT id, title, filename, category FROM images;"
```
